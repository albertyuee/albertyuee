## Selected projects

### [Deep Research Agent](https://github.com/albertyuee/deep-research-agent)

An Agentic RAG research system that decomposes complex questions, selects retrieval strategies, critiques evidence quality, retries when needed and produces source-linked reports.

- Hybrid retrieval: vector search + BM25 + reciprocal-rank fusion
- Optional reranking and multi-hop research workflows
- Source citations, FastAPI SSE streaming and document permissions
- Fixed retrieval evaluation tooling with Hit@K, MRR, source recall and latency metrics

### [SQL Agent Kit](https://github.com/albertyuee/sql-agent-kit)

A natural-language data analysis application that turns questions into SQL, charts and short summaries.

- Multi-step planning, SQL validation and bounded execution
- Physical-table allowlist checks for nested queries
- Confidence signals, retry handling and query history
- FastAPI backend, Vue 3 frontend, SQLite demo data and MySQL/PostgreSQL connectors

### [Data Analytics MCP Hub](https://github.com/albertyuee/MCP_Hub)

MCP servers that connect AI clients to MySQL and Hive through stdio or SSE.

- Schema inspection, query tools, query plans and Hive partitions
- Local management UI and client integration examples
- Explicit data-flow and deployment-boundary documentation
