## How I approach AI engineering · 我的工程方法

| English | 中文 |
| --- | --- |
| Start with a concrete workflow, not a fashionable model. | 从具体业务流程开始，而不是从热门模型开始。 |
| Make retrieval, tool calls and failures inspectable. | 让检索、工具调用和失败过程可观察。 |
| Evaluate quality with repeatable cases before claiming improvement. | 在声称效果提升前，用可重复案例进行评估。 |
| Keep permissions, data flow and deployment boundaries explicit. | 明确权限、数据流和部署边界。 |
| Prefer a small reliable system over a large impressive demo. | 优先构建小而可靠的系统，而不是庞大但脆弱的 Demo。 |
